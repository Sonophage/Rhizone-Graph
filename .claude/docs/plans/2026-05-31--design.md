# Rhizone Graph — Design

> A local-first **connection-web** view for Obsidian. Replaces the non-functional native graph and
> the heavier Cortical Engram Cartograph with one purpose-built instrument: given a note, show what
> it connects to, what it *could* connect to, and let you forge those connections by hand.

- **Status:** design locked (brainstorm + roundtable complete). Ready for implementation plan.
- **Date:** 2026-05-31
- **Repo:** `Sonophage/Rhizone-Graph/` (sibling plugin; symlinked into vault as `rhizone-graph`)
- **Author:** Sonophage · MIT

---

## 1. Why this exists

The native Obsidian graph and the Cartograph both answer "what does *everything* look like at once" —
a question with no useful answer at vault scale. Force-directed layout settles nodes by physics, not
meaning, so position encodes nothing and the result is an admire-for-four-seconds hairball.

A measurement of the Harker vault (314 notes) made the real structure obvious:

| Signal | Count | Meaning |
|---|---|---|
| Resolved note→note links | 382 | sparse; the *stated* web |
| **Phantom links** (target not a note) | **1,275** | the dominant structure |
| Distinct phantom targets | 689 | genres, people, franchises, projects |
| Orphans | 5 | a non-problem |
| Notes with ≥1 co-citation partner | 279 / 314 | discovery signal is live almost everywhere |

**The vault links notes to *facets*, not to notes.** `[[Science Fiction]]`, `[[Vlad]]`, `[[Opaline]]`,
`[[ForeverCraft]]` are not missing notes — they're a faceted tag system expressed in wikilink syntax.
This is *why* the native graph is noise (its biggest hubs are genre labels and `.jpg` filenames) and
*why* co-citation is the right engine: two notes that share rare facets are genuinely related even
when neither links the other.

**Validated example (the regression oracle):** candidates for `Concept - The Demiurge` rank
`The Great Architect` #1, and surface `Movies - Blade Runner 2049` via a single shared `[[Philip K. Dick]]`
facet — a movie next to a theology note, by an unstated throughline. That is the payoff.

## 2. The three layers (core model)

| Layer | Direction | Source | Role |
|---|---|---|---|
| **Facets** | note → concept | every `[[wikilink]]` target (resolved + phantom), minus attachments | feeds co-citation |
| **Inline links** | note → note | resolved wikilinks in prose | incidental "mentioned" |
| **`connections`** | note ↔ note | curated frontmatter property | the deliberate, blessed web |

Node **state** (precedence: Connected > Mentioned):

- **Connected** — in `connections:` → solid/anchored.
- **Mentioned** — inline `[[link]]` only → dim.
- **Candidate** — co-citation only, no link → bright (serendipity).

## 3. Engine (pure, no embeddings)

- **Facets** = all wikilink targets from `metadataCache` (`links` + `frontmatterLinks`), resolved or
  phantom, **excluding** attachment extensions (`.jpg/.jpeg/.png/.gif/.webp/.svg/.pdf/.base`).
- **Alias-strip (matching only, never rewrites files):** normalize `Concept - X` ≡ `X`; fold display
  aliases. Lets `[[The Archons]]` and `[[Concept - The Archons]]` count as one facet.
- **Co-citation:** two notes are candidates iff they share ≥1 facet.
- **Ranking — "rarity beats count":** sort candidates by their *rarest* shared facet (lowest
  document-frequency `df`) ascending; tiebreak by weighted sum `Σ 1/df`. A single rare facet outranks
  many common ones.
- **Inverted index:** `facet → Set<notePath>` and `notePath → Set<facet>`; `df` cached. Built once on
  load; **incrementally** updated on `metadataCache.on('changed')` for the touched file only — never a
  full rescan.
- The engine has **zero Obsidian imports**. It operates on plain records
  `{ path, facets, outLinks, connections }` and returns ranked results. Fully unit-testable.

## 4. View (SVG concentric rings)

- **Radius = tier.** Center = focus note. Inner ring = direct links + `connections`. Outer ring =
  co-citation candidates.
- **Outer ring:** already-linked notes shown **dimmed** (context); true candidates **bright**.
  **Top 10**, with a paginated **"show more"** (dense hubs can have hundreds).
- **State via multiple channels** (never brightness/color alone — CRT/glass theme + a11y):
  brightness **+** stroke style **+** state glyph (● Connected / ○ Mentioned / ◇ Candidate) **+**
  `aria-label`.
- **Direct links:** presence only (no in/out direction).
- **Persistent legend** (doubles as the in-app explanation of the model).
- **SVG**, not canvas: ≤ ~30 visible nodes → free hit-testing, CSS theming via Bureau tokens, a11y.
- **Theme-aware:** all colors via CSS custom properties so the Bureau theme (dark/daylight/glass/CRT)
  drives appearance.

## 5. Interactions

- **Traverse:** click *any* node (dim or bright) → it becomes the new center, rings recompute.
  Serendipity regenerates each hop. A **clickable breadcrumb trail** records the walk (back/branch).
- **Why:** hover/focus a candidate → shows the shared facets, **rarest first** ("because you both tag
  Philip K. Dick, Simulation Theory").
- **Forge:** promote a candidate into `connections:` on **both** notes. Writes via
  `app.fileManager.processFrontMatter` only — **never manual YAML**. Sequenced + **idempotent**
  (re-run heals a half-written pair, never duplicates; dedupe + self-reference guard).
- **Preview:** inline note content via `MarkdownRenderer` (no `innerHTML` of note bodies).
- **Keyboard-first:** Tab cycles ring nodes, Enter traverses, **F** forges. Mouse optional.

## 5b. Visual design — "The Scope" (chosen direction)

A Bureau/Control **CRT targeting scope** — the name *Rhizone* → reticle/graticule drives the look.

- **Geometry:** focus note as a `⊕` reticle mark at center on faint crosshair axes. Two **dotted
  graticule range-rings**, faintly arc-labeled `DIRECT` (inner) / `CO-CITATION` (outer). Contacts sit on
  their ring, **rarest-first from 12 o'clock, clockwise** (strongest candidate = due north). Dotted
  **leader lines** from center to each contact; label just outside the ring.
- **State channels** (multi-channel, never color alone): Connected `●` filled / solid leader / full;
  Mentioned `○` hollow / dashed leader / dimmed; Candidate `◇` diamond / accent / dotted leader / faint pulse.
- **Operator readouts** (this replaces any "see also" list): focusing a contact lights a one-line readout
  `CONTACT · {title} — shared: {facets rarest-first}`. Focused candidate shows `[ designate ↵ ]` (Enter/F).
  `track:` breadcrumb under the bezel header; persistent legend strip at bottom.
- **Chrome:** thin single-line bezel (`┌ RHIZONE ░ … ┐`); frosts when the Bureau **glass mode** is active,
  else a solid console panel.
- **Color (decided):** **inherit Bureau accent tokens by default** (candidate = accent, connected =
  ink/foreground, mentioned = muted) so it adapts to dark/daylight/glass/accent-presets; plus a
  **Style-Settings "phosphor override"** (amber/green) for pure-CRT mono mood.
- **Motion (decided):** scanline + a radar **sweep on recompute (traverse)**, as **Style-Settings sliders
  defaulting low** (not off), honoring `prefers-reduced-motion`. Mirrors the theme's atmosphere-slider pattern.

## 6. Dangling connections (remediation module)

When a `connections` target is renamed or deleted, the entry is **flagged, never auto-pruned**.
A small remediation affordance offers: **Reconnect** (pick the moved note) · **Repoint** (to a new/other
note) · **Delete connection**. (Obsidian's own rename-link updating handles many renames in frontmatter
wikilinks; this module covers the cases it doesn't.)

## 8. Non-goals (resist scope creep)

- **No global graph.** This plugin's virtue is that it shows one note's neighborhood. Never re-add a
  whole-vault view.
- **No embeddings / no ML / no network.** Pure structure keeps it light — the explicit reason it beats
  the Cartograph.
- **No auto-population of `connections`.** The property is curated by hand; the plugin only writes it on
  an explicit forge. (Engine candidates are ephemeral, never persisted.)
- **No file rewrites for matching.** Alias-strip is internal only; the `Concept - ` prefix stays.

## 9. Success criteria (cs-verify gates)

- [ ] Engine golden tests pass — the Demiurge ranking reproduced (Great Architect #1; Blade Runner 2049
      surfaces via `[[Philip K. Dick]]`; rarity beats count).
- [ ] Forge writes both sides; re-running heals, never duplicates (idempotency test).
- [ ] Zero manual YAML writes in the codebase (grep gate; all via `processFrontMatter`).
- [ ] View is keyboard-navigable end-to-end (Tab / Enter / F).
- [ ] State distinguishable in grayscale (no reliance on color/brightness alone).
- [ ] Index updates incrementally on file change (no full rescan).
- [ ] Dangling connection is flagged (not pruned) and remediable.
