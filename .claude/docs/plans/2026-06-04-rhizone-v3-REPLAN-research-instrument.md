# Rhizone v3 — REPLAN: the research instrument (supersedes the "daily oracle" plan)

Grounded in the user's 20 answers (2026-06-04). The earlier v3 "daily driver / today's door"
framing is **retired** — wrong model.

## Identity (locked)
- **Reticular = the neighborhood.** Daily, always-open, fast, focused. See what's connected and
  what's not, jump through notes while working. **It works — leave it alone** (only touch it for the
  peer-jump below). Stays visually "focused," not mystical.
- **Rhizone = the city.** Opened *on demand, at random*, for **research and thought**: finding the
  *path between* notes — the space between them — and surprising chains (Gnosticism → Philip K. Dick
  → Blade Runner). Mystical, tactile, data-rich. This is the thing we elevate.
- **Layout:** side-by-side; Reticular always open, Rhizone summoned when needed. **Always synced**
  (Rhizone summon → Reticular follows) with a **pin** on either to break the sync and compare.
- **Tandem loop:** Rhizone *feeds* Reticular (find the strange → forge → it becomes resident). Make
  it a true **peer loop** by adding the reverse: a Reticular node → "research in Rhizone."

## What DIES from the old plan
- ❌ date-seeded "today's door" as a daily ritual (he opens at random, not daily)
- ❌ depletion meter / any sense of progress (Q18: "i dont want to sense progress")
- ❌ streak / completionist framing

## What's NEW / changed (priority order)

### P1 — PATHFINDING (the headline; was missing entirely)
"How does A connect to B?" Pick two notes (or A = active note, B = chosen/searched) → trace the
**chain of connection** through shared facets / co-citation, render it as a **walkable path of stairs**,
each hop labelled with the shared facet ("via"). The Gnosticism→PKD→Blade Runner experience. This is
why Rhizone exists for him. Engine: shortest/strongest path over the facet-cocitation graph.

### P2 — THE TRAIL (research history; Q20)
A breadcrumb of the **doors walked + stairs built** this session — your research path, retraceable,
step back/forward. Reuse Reticular's `BreadcrumbTrail`. Thesis-safe (a trail, not a map).

### P3 — OFFERINGS, reframed (Q9, Q11, Q12) — fold in the built A1
On open, **several** research starting points seeded from CONTEXT, not a date: the **active note**,
your **frequently-opened** notes/ghosts (Q11: "you keep opening this"), and ripe coincidences. Augments
the note you're writing (live alongside). The existing "today's door" mechanism survives here, minus
the daily/streak skin.

### P4 — SIGNAL & DATA (Q14, Q15, Q16) — he LOVES numbers
- Numbers visible: df/rarity, shared-facet counts, influence, open-frequency. A data readout.
- Node size = **rare OR cluster-central** (his pick for "worth looking at").
- **Stable constellation names** (he explicitly wants names he learns — overrides the council's
  ephemeral-names worry; his call).

### P5 — FILTER (Q13)
Hide note **types/folders** (templates, daily notes, …) from the whole view. Setting + quick toggle.

### P6 — ATMOSPHERE, Rhizone-only (Q17, Q19)
The mystical instrument feel — ignition-on-open, summon-as-gravity, divination frame, living idle.
**One shared visual language**, exception: **Rhizone mystical / Reticular focused**. Flourish stays —
"it's what keeps me" — but never on Reticular (speed).

## Suggested build order
P5 filter (quick unblock; cleaner views immediately) → **P1 pathfinding** (the soul) → P2 trail →
P3 offerings-reframe → P4 signal/data + names → P6 atmosphere. Peer-jump (Reticular→Rhizone) slots
in after P1. Build + 55 engine tests green each step; pathfinding gets its own unit tests.
